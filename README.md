## 📌 Overview

**Financial Advisor AI** is a conversational AI application developed using **Dify** and Generative AI.

The application allows users to ask questions related to personal finance, including budgeting, saving money, expenses, financial planning, and basic investment awareness.

The project demonstrates how **Generative AI, Prompt Engineering, and Conversational AI** can be applied to the financial domain.

> ⚠️ **Disclaimer:** Financial Advisor AI is an educational and informational project. It does not replace professional financial advisors or provide guaranteed financial returns.

## ⚙️ How It Works

1. The user opens the **Financial Advisor AI** application.
2. The user enters a financial question or provides financial details.
3. The input is processed through the configured **Dify workflow**.
4. The Financial LLM analyzes the user's request.
5. The Financial Analysis LLM processes the financial information and provides suitable recommendations.
6. The Doubt Clarification module explains financial concepts when required.
7. The generated response is displayed to the user through the chatbot interface.

## 🧠 Prompt Engineering

Prompt Engineering was used to control the behavior and responses of the Financial Advisor AI.

The prompts were designed using:

- **Role** – Defines the AI as a Financial Advisor
- **Context** – Provides financial information and user requirements
- **Task** – Defines what the AI needs to analyze or explain
- **Instructions** – Guides the AI to provide simple and practical responses
- **Response Format** – Encourages clear and easy-to-understand answers
- **Constraints** – Prevents risky or guaranteed financial advice
- **Safety Guidelines** – Promotes responsible financial decision-making

Different LLM modules were configured for:

- 💰 Financial Assistance
- 🧠 Financial Analysis
- ❓ Doubt Clarification
